# Team3 打包与分发设计

## 一句话

将 web + daemon 打包为一个 npm package（team3），prompts 混淆嵌入 daemon，用户 `npm install -g team3` 即用。

---

## 目标

1. **好上手**：一条命令安装，一条命令启动
2. **IP 保护**：human_coding/ 下所有 prompt（含 team3.md）不以明文出现在用户磁盘
3. **开发者不受影响**：手工按 human_running.md 自开发时，路径直达、无间接层

---

## 两种模式（仅两种，无中间态）

| 模式 | 谁在用 | prompt 来源 | 怎么传给 claude |
|------|--------|------------|----------------|
| **手动 session** | 开发者在终端 | `human_coding/xxx_prompt.md` 文件 | `--system-prompt-file human_coding/arch_prompt.md` |
| **daemon 调度** | 开发者 UI dogfood / 终端用户 | `daemon/src/embedded-prompts.js`（构建时生成） | `--system-prompt "<inline>"` |

daemon 模式下 dev 和 prod 无区别——都走 embedded prompts。区别只是 daemon 入口不同（源码 vs 打包产物）。

## 构建流程

### `build/embed-prompts.js`

1. 读 `./team3.md`，删除目录结构中 `agents/` 描述段
2. 读 `human_coding/{arch,dev,uat}_prompt.md`
3. 每个 role prompt 中 `**FIRST**: Read human_coding/team3.md ...` → 替换为 team3.md 内容内联
4. 输出 `daemon/src/embedded-prompts.js`：

```js
// AUTO-GENERATED by build/embed-prompts.js — do not edit
module.exports = {
  arch: `<team3.md 处理后>\n\n---\n\n<arch_prompt.md 去掉 FIRST 行>`,
  dev:  `<team3.md 处理后>\n\n---\n\n<dev_prompt.md 去掉 FIRST 行>`,
  uat:  `<team3.md 处理后>\n\n---\n\n<uat_prompt.md 去掉 FIRST 行>`,
};
```

开发者首次 clone 后、修改 prompt 后，需执行 `node build/embed-prompts.js` 重新生成。

### `build/build.sh`

```bash
#!/bin/bash
set -euo pipefail
TOOL_DIR="$(cd "$(dirname "$0")/.." && pwd)"

# 1. 合并 prompts
node "$TOOL_DIR/build/embed-prompts.js"

# 2. daemon bundle + 混淆
cd "$TOOL_DIR"
npx esbuild daemon/src/orchestrator-entry.js \
  --bundle --platform=node --target=node20 --outfile=dist/daemon.bundle.js
npx javascript-obfuscator dist/daemon.bundle.js \
  --output dist/daemon.min.js \
  --string-array true --string-array-encoding base64 \
  --control-flow-flattening true

# 3. web standalone build
cd "$TOOL_DIR/web" && npm run build && cd "$TOOL_DIR"

# 4. 组装 npm package
rm -rf pkg && mkdir -p pkg/{bin,server,assets/cli,assets/ref}
cp bin/team3.js pkg/bin/
cp -r web/.next/standalone/* pkg/server/
cp -r web/.next/static pkg/server/.next/static
cp dist/daemon.min.js pkg/
cp cli/*.mjs pkg/assets/cli/
cp human_coding/{tech-stack,arch-ui,dev-ui,dev-init-sh,dev-html-prototype,uat-scaffold}.md pkg/assets/ref/
node build/gen-package-json.js > pkg/package.json

# 5. pack
cd pkg && npm pack
```

## daemon prompt 传递（无条件 embedded）

已迁移至 `code-cli/` provider 体系（详见 `app_codecli_fit.md`）。`claude-args.js` 已删除，各 provider 内部的 `buildArgs()` 负责参数构造，embedded prompts 通过 `--system-prompt` 内联传递。

如果 `embedded-prompts.js` 不存在（开发者忘了生成），daemon 启动时直接报错——提示执行 `node build/embed-prompts.js`。

## initWorkspace 改动

```ts
const SKELETON_DIRS = ["spec", "cli", "uat", "logs"];

const SKELETON_FILES: Record<string, string> = {
  "spec/app_design.md": "# App Design\n\n> Write your product architecture here.\n",
  "spec/actions.jsonl": "",
  "spec/decisions.md": "# 生效的人类决策\n",
  "spec/experience.md": "# Agent 经验教训\n",
};

function getCliSourceDir(): string {
  if (process.env.TEAM3_PKG_DIR) {
    return path.join(process.env.TEAM3_PKG_DIR, 'assets', 'cli');
  }
  // dev mode: web/ 的兄弟目录 cli/
  return path.join(process.cwd(), '..', 'cli');
}

const CLI_FILES = [
  'simulate_human.mjs', 'logger.mjs', 'browser.mjs', 'watchdog.mjs',
];

export function initWorkspace(workspacePath: string): void {
  const absPath = path.resolve(workspacePath);
  fs.mkdirSync(absPath, { recursive: true });

  for (const dir of SKELETON_DIRS) {
    fs.mkdirSync(path.join(absPath, dir), { recursive: true });
  }

  for (const [rel, content] of Object.entries(SKELETON_FILES)) {
    writeIfNotExists(path.join(absPath, rel), content);
  }

  // copy cli scaffold
  const cliSrc = getCliSourceDir();
  for (const file of CLI_FILES) {
    const src = path.join(cliSrc, file);
    const dest = path.join(absPath, 'cli', file);
    if (fs.existsSync(src)) writeIfNotExists(dest, fs.readFileSync(src, 'utf-8'));
  }

  // .team3-project.json
  const pjPath = path.join(absPath, '.team3-project.json');
  if (!fs.existsSync(pjPath)) {
    fs.writeFileSync(pjPath, JSON.stringify(buildDefaultProjectJson(absPath), null, 2) + '\n');
  }
}
```

删除：AGENT_TEMPLATE_FILES、getTemplatesDir()、agent prompt copy、modules_progress.json 创建。
删除：`web/templates/` 整个目录。

## bin/team3.js

```
team3 start    → mkdir -p ~/.team3/logs
               → spawn node server/server.js (env: TEAM3_PKG_DIR, PORT=3000)
               → 等就绪 → 打开浏览器

team3 stop     → kill web 进程

team3 version  → 读 package.json version
```

daemon 不由 CLI 启动——per-project、从 workspace UI 按需启动。

## 动线一：用户视角

### 安装

```bash
npm install -g team3
```

### 启动

```bash
team3 start
```

→ `~/.team3/` 创建 → Next.js standalone :3000 启动 → 浏览器打开

### 创建项目

Create Project → name=pro_110, path=~/work
→ `initWorkspace("~/work/pro_110")`
→ 创建 spec/（3 文件）+ cli/（4 文件）+ uat/ + logs/ + .team3-project.json
→ 注册 `~/.team3/projects.json`

### 启动 Daemon

点击"启动 Daemon"
→ spawn `node $TEAM3_PKG_DIR/daemon.min.js`（内含 watchdog 重启逻辑）
→ daemon 加载 embedded prompts（已打包在内）
→ WS 就绪 → 前端绿点

### Agent 执行

用户发消息 → daemon 路由到 arch → spawn：
```
claude -p "消息" --system-prompt "<合并后的完整 prompt>" --session-id "uuid" --output-format stream-json --verbose
```
agent CWD = ~/work/pro_110/，读 spec/、用 cli/、写 uat/。
用户磁盘上无任何 prompt 文件。

## 动线二：开发者手工自开发

### 前提

CWD = `team3/`。`human_coding/` 在 CWD 内。

### 首次设置（clone 后执行一次）

```bash
cd team3
npm install --prefix web && npm install --prefix daemon
node build/embed-prompts.js    # 生成 daemon/src/embedded-prompts.js
```

### 手动启 Arch

```bash
cd team3
claude --session-id "86a05a3a-..." --system-prompt-file human_coding/arch_prompt.md
```

→ prompt 第一行 `FIRST: Read human_coding/team3.md`
→ claude Read `./team3.md`（CWD=team3/，直达）✓
→ 读 spec/app_design.md 等 ✓

### 手动启 Dev

```bash
claude --session-id "8d37dc10-..." --system-prompt-file human_coding/dev_prompt.md
```

同上。✓

### UI dogfood

```bash
cd team3/web && npm run dev
```

→ 创建测试项目 → cli/ 从 `../cli/` copy ✓
→ 启动 Daemon → spawn `../daemon/src/orchestrator-entry.js`
→ daemon `require('./embedded-prompts')` → 已生成 ✓
→ 行为与 prod 完全一致

### 修改 prompt 后

```bash
# 编辑 human_coding/arch_prompt.md
node build/embed-prompts.js    # 重新生成 embedded-prompts.js
# 手动 session：下次新 session 读最新文件
# daemon：重启 daemon 后生效
```

### 发布

```bash
bash build/build.sh
# 产出 pkg/team3-x.y.z.tgz
```
